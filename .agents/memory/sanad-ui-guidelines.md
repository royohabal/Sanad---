name: SANAD interface direction
description: Project-specific guidance for SANAD navigation, copy, palette, and Arabic layout.
---

Keep SANAD concise and multi-page: public entry stays short, while worker and company tasks live on dedicated routes with compact navigation. Use the existing burgundy, coral, and warm cream palette; support Arabic with proper right-to-left layout. Preserve real authentication, API data, and payment behavior rather than substituting mocks.

**Why:** the user explicitly requested a minimal, task-focused redesign with distinct pages and consistent Arabic RTL.

**How to apply:** when changing SANAD UI, remove redundant copy and sections, keep each page focused on its task, and retain existing integrations.
